# Tactical Syndicate HQ (faction 55410)

Static site, no server needed. Open `index.html` or host on GitHub Pages:
1. Create a repo, upload `index.html`.
2. Settings > Pages > deploy from `main` branch, root.
3. Open the Pages URL, paste your Torn API key, click Connect.

Leaders: use a key with faction (Limited/Full) access to see vault, armory and crimes data.
Members: any key works for roster, activity and war data. The key stays in your own browser and calls api.torn.com directly.
Trade ledger, announcements and weekly snapshots are stored in each browser (use the CSV exports to share).
Torn returns only the latest 100 attacks, so hit totals cover that window.
